# 语言偏好

- 始终使用中文（简体中文）与用户交流，包括最终回答、过程说明、提问、进度提示等所有面向用户的文字。
- 编写 spec 文档（requirements.md、design.md、tasks.md 等）时，正文使用中文。
- 代码注释、提交信息（commit message）和文档说明优先使用中文，除非项目已有相反约定。
- 技术专有名词、API 名称、命令、代码标识符等可保留英文原文，不强行翻译。
- EARS 关键字（WHEN、IF、WHILE、WHERE、THEN、THE、SHALL）按规范保留英文，其余描述用中文。
